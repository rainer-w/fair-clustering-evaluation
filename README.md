# Are We Evaluating Fair Clustering Fairly? Benchmarks, Protocols and Data Generation for non-convex Fair Clustering

## Repository Structure

data_uci/       Datasets from UCI repository 
experiments/   Scripts reproducing experiments
figures/        Non experiment-related figure generation
results/       Output generated by experiments
src/           Core implementation
## Installation

pip install -r requirements.txt


## Reproducing the Paper

Run experiments from root repository
eg. to produce results for the UCI experiments run: 
python -m experiments.realworld.run_all_uci



## List of Available Parameters for DEBRIS: 
dim : Number of Dimensions
clunum : Number of Clusters
core_num : Number of Cores 
ratio_noise : Ratio of Noise Samples in Data 
seed : Random Seed
g : Number of Sensitive Attribute Values 
distr : Distribution of Sensitive Values in Subgroups (eg. [[0.9,0.1],[0.1,0.9]]) -> two subgroups each dominated by either value which the attribute can take 
gap : the number of cores that separate individual subgroups within a cluster
clu_ratios : distribution of data points across clusters (eg. by default: clu_ratios = np.ones(clunum) / clunum, creates clusters of equal densities)
