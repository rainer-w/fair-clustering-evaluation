# Datasets

The datasets used in the experiments are not included in this repository.

Please download the datasets from the following sources:

- Adult: https://archive.ics.uci.edu/dataset/2/adult
- Bank Marketing: https://archive.ics.uci.edu/dataset/222/bank+marketing
- Census: https://archive.ics.uci.edu/dataset/116/us+census+data+1990
- Default of Credit Card Clients: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
- Diabetes 130-US Hospitals: https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008

After downloading and extracting the datasets, organize the files according to the following structure:


data_uci/
├── Adult/
│ └── adult.data
├── Bank/
│ └── bank-full.csv
├── Census/
│ └── USCensus1990.data.txt
├── Creditcard/
│ └── creditcard_data.xls
└── Diabetes/
└── diabetic_data.csv


The experiments expect the datasets to be available at these locations.
